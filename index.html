Late login form autofill repro

Plain HTML login form, inserted into the DOM ?delay=N ms after the load event (default 1000). This mimics SPAs and web components that render the login form after async fetches. Use ?delay=static for a form present in the initial HTML, as a baseline.

Repro: save a login for this URL, enable autofill on page load, reload. Compare ?delay=static with ?delay=1000. Manual fill from the in-field icon works in both.
